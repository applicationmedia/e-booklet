E-FLIPBOOK IMUNISASI DPT — FULLSCREEN

Isi paket:
- index.html: halaman flipbook fullscreen
- assets/page-01.jpg sampai page-12.jpg: halaman booklet
- assets/audio-01.mp3 sampai audio-12.mp3: audio per halaman

Cara publikasi:
1. Ekstrak ZIP.
2. Unggah folder eflipbook_imunisasi_dpt ke layanan hosting website statis, atau unggah isi foldernya sesuai instruksi hosting.
3. Pastikan index.html dan folder assets berada pada lokasi yang sama.

Perilaku:
- Saat tautan dibuka, website mencoba memutar audio halaman pertama secara otomatis.
- Sebagian browser memblokir audio otomatis yang bersuara. Jika diblokir, akan muncul tombol minimal “Mulai audio” untuk memulai sesi.
- Setelah audio selesai, tombol “Halaman berikutnya” muncul. Pengguna menekannya untuk lanjut; audio halaman berikutnya lalu diputar.
- Pada halaman terakhir, tidak ada tombol berikutnya.
